# Model column canonical names

The `Model` column of the history tables uses exactly these spellings. When
recording a deletion row, pick the entry that matches the model that did the
work; do not invent a variant.

## Claude family (prefix `Claude `, space before the number, no parentheses)

- `Claude Opus 5`
- `Claude Opus 5.5`
- `Claude Opus 4.8`
- `Claude Opus 4.7`
- `Claude Fable 5`
- `Claude Fable 5.1`
- `Claude Sonnet 5`
- `Claude Sonnet 5.5`

No context-window suffix (the old ` (1M context)` is dropped) and no lane or
stage annotations (the old `the close: ...` parentheticals are dropped). When
one row has several models, separate them with `, ` and give each the full
canonical name, e.g. `Claude Opus 5, Claude Fable 5.1`.

A reviewer that is not the worker goes in parentheses after the worker, e.g.
`ggml-org/Qwen3.8-27B-GGUF:Q4_K_M (reviewed by Claude Opus 5)`.

## The attribution precedence (unchanged, from the project CLAUDE.md)

The model recorded is the one that did the work. A subagent inherits the
parent's `Co-Authored-By` trailer, so the trailer is a hint, not the answer.
