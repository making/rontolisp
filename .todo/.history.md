# Deleted todo items

A row is added whenever a `.todo/NNN-*.md` file is removed, recording the commit that
removed it. The commit itself is the detail; this table is the index. `Model` is the
model that did the WORK, named as in that work's `Co-Authored-By` trailer -- which is
not always the model that removed the file (an item can outlive the model that wrote it).

To read a deleted item's content, take its row's `Commit` and `File` and run
`git show <Commit>~:<File>` -- `Commit` is the commit that removed the file, so its
parent still contains it. Every row must keep this invariant. Each `Commit` cell is
also linked as `https://github.com/making/rontolisp/blob/<commit>~/<file>` so the
deleted item can be read directly on GitHub.
