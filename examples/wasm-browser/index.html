Running rontolisp WASM in plain HTML + JavaScript

The two programs below were written in Lisp and compiled ahead of time to WebAssembly (WASI Preview 1) with rontolisp. This page provides a tiny WASI shim in JavaScript, instantiates each .wasm module, runs its _start, and shows whatever it printed to stdout. No server, no framework.

Want to write Lisp and compile it to WASM in the browser, then run the result here? See the playground and its compile & run page (these links work on the published site).

1. Run a self-contained program

hello.wasm computes Fibonacci numbers and some exact rational arithmetic, printing the result. Click to run it in your browser.
