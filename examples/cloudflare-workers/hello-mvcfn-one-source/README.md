# hello-mvcfn-one-source — one WebMvc.fn file, a JDK and five hosts, this one included

There is **no Java in this directory**. The program is
[`java/hello-mvcfn`](../../java/hello-mvcfn)'s
[`HelloMvcfn.java`](../../java/hello-mvcfn/src/main/java/HelloMvcfn.java) *itself* —
one `GET /` route written as a function in the style of Spring MVC's WebMvc.fn,
behind a `DispatcherServlet` on
[`servlet-httpserver`](https://github.com/making/rontolisp/tree/develop/servlet-httpserver).
A JDK runs the file as it stands, on
[`webmvc-fn-lite`](https://github.com/making/rontolisp/tree/develop/webmvc-fn-lite)
or on Spring Framework's own `spring-webmvc`. Compiled by rontolisp's
**experimental** subset of the Java language it binds a socket on the
interpreter, the JVM and in a native executable and serves under
`wasmtime serve`; here it is compiled for a host that **calls an export** instead
of handing over a socket.

```bash
./build.sh          # ../../java/hello-mvcfn/src/main/java/HelloMvcfn.java -> src/worker.wasm + src/worker.js + src/index.js
npx wrangler dev    # http://localhost:8787
npx wrangler deploy
```

```console
$ curl http://localhost:8787/
Hello World!
$ curl -i http://localhost:8787/nope
HTTP/1.1 404 Not Found
```

Everything else is documented once, in
[`../hello-servlet-one-source`](../hello-servlet-one-source): the
[hosts](../hello-servlet-one-source/README.md#one-source-a-jdk-and-five-hosts)
the one file serves on and
[what a Worker does not give a Java program](../hello-servlet-one-source/README.md#what-a-worker-does-not-give-a-java-program).
A larger WebMvc.fn application, [`java/mvcfn`](../../java/mvcfn) — JSON bodies,
path variables, an error handler — answers the same on this transport as on the
others (`FetchSpecE2eTest#javaHttpServer`, its `mvcfn`).

## What's in here

| File | Purpose |
| --- | --- |
| [`../../java/hello-mvcfn/src/main/java/HelloMvcfn.java`](../../java/hello-mvcfn/src/main/java/HelloMvcfn.java) | **The whole program** — not in this directory, deliberately |
| [`build.sh`](build.sh) | `--no-wasi --host-output --optimize=size --emit-worker-entry` over that file, the container and `webmvc-fn-lite` read from this checkout's sources and the Servlet API from its sources jar |
| `src/index.js` | Written by `./build.sh` (`--emit-worker-entry`) on the first build: three lines over the generated `worker()`. Yours to edit; a later build never overwrites it |
| [`src/worker.js`](src/worker.js) | The boundary, GENERATED by `--emit-js-glue` and pinned by `HostGlueEmitterTest`: the file [`../hello-servlet-one-source`](../hello-servlet-one-source) gets, since the declarations are the same. Do not edit; `./build.sh` rewrites it |
| `src/worker.wasm` | A build product — run `./build.sh` first |

## Rebuilding

```bash
./mvnw clean package -DskipTests   # from the repository root
examples/cloudflare-workers/hello-mvcfn-one-source/build.sh
```
