# hello-servlet-one-source — one Java file, a JDK and five hosts, this one included

There is **no Java in this directory**. The program is
[`java/hello-servlet`](../../java/hello-servlet)'s
[`HelloServlet.java`](../../java/hello-servlet/src/main/java/HelloServlet.java)
*itself* — one lambda servlet on
[`servlet-httpserver`](https://github.com/making/rontolisp/tree/develop/servlet-httpserver),
the file a JDK runs as it stands. Compiled by rontolisp's **experimental** subset of
the Java language it binds a socket on the interpreter, the JVM and in a native
executable and serves under `wasmtime serve`; here it is compiled for a host that
**calls an export** instead of handing over a socket.

```bash
./build.sh          # ../../java/hello-servlet/src/main/java/HelloServlet.java -> src/worker.wasm + src/worker.js + src/index.js
npx wrangler dev    # http://localhost:8787
npx wrangler deploy
```

```console
$ curl http://localhost:8787/
Hello World!
```

## One source, a JDK and five hosts

`ServletHttpServer.start()` serves through `com.sun.net.httpserver`, and that
server serves through the transport of the compile target:

| Build | Who owns the port | How it runs |
| --- | --- | --- |
| a JDK | the program binds it | `mvn exec:exec` in [`java/hello-servlet`](../../java/hello-servlet) |
| interpret | the program binds it | `rontolisp HelloServlet.java` with the libraries below |
| `-o Hello.class` | the program binds it | `java Hello` |
| `--native -o hello` | the program binds it | `./hello` |
| `-o hello.wasm --component` | the wasi:http host | `wasmtime serve hello.wasm` |
| `-o worker.wasm --no-wasi` | Cloudflare | this directory: the generated `src/worker.js` calls `handle-request` |

`main` runs once, when the Worker's instance starts. `start()` hands the
application to the reactor instead of binding the port, `main` returns, and each
request is one call of the export. `System.getenv("PORT")` answers `null` on a
Worker, so the port the program names is the one nobody binds. What it
prints is the Worker's log (`--host-output`): standard output to
`console.log`, standard error to `console.error`, which `wrangler tail` shows.

[`examples.yaml`](../../examples.yaml) pins the class, the component and this
module, all built from the one file; `FetchSpecE2eTest#javaHttpServer` asks the
same requests of every transport, this one under node through the generated
glue.

## What a Worker does not give a Java program

A reactor answers within its host's call and has no process of its own:

- **No time passes within a call.** `Thread.sleep`, a wait with a time limit that
  no other thread ends, and a request waiting for what another request brings
  end the instance: the call fails, the Worker answers `500`, and the next
  request starts the program anew. A thread the handler starts and joins runs.
- **`System.exit` ends the instance** in the same way, as does an exception
  `main` leaves uncaught. What the program reported before it ended is in the
  log, beside the `RuntimeError: unreachable` of the failed call.
- **State is the instance's.** A static field and a session in memory live as
  long as the isolate does.
- **Entropy, outgoing requests and binary bodies are opt-ins of the build**:
  `--host-random` for `SecureRandom` (a session's id), `--host-boundary=streaming`
  for a body that is not text. `java.net.http` and JDBC are not wired to a
  Worker yet.

[A Worker](../../../doc/en/java/index.md#a-cloudflare-worker) in the Java
section has the details.

## What's in here

| File | Purpose |
| --- | --- |
| [`../../java/hello-servlet/src/main/java/HelloServlet.java`](../../java/hello-servlet/src/main/java/HelloServlet.java) | **The whole program** — not in this directory, deliberately |
| [`build.sh`](build.sh) | `--no-wasi --host-output --optimize=size --emit-worker-entry` over that file, the container read from this checkout's sources and the Servlet API from its sources jar |
| `src/index.js` | Written by `./build.sh` (`--emit-worker-entry`) on the first build: three lines over the generated `worker()`. Yours to edit; a later build never overwrites it |
| [`src/worker.js`](src/worker.js) | The boundary, GENERATED by `--emit-js-glue` and pinned by `HostGlueEmitterTest`: the file [`../ring-hello-one-source`](../ring-hello-one-source) gets, since the declarations are the same, plus the `--host-output` log. Do not edit; `./build.sh` rewrites it |
| `src/worker.wasm` | A build product — run `./build.sh` first |

## Rebuilding

```bash
./mvnw clean package -DskipTests   # from the repository root
examples/cloudflare-workers/hello-servlet-one-source/build.sh
```

The build prints one line about `%NANO-TIME`: the program's start can read the
clock, which a `--no-wasi` module takes from its host. The generated glue sets it
before the instance starts and before each call.
