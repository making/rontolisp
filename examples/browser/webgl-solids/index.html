solids.lisp → WebGL

The geom solid modeller shipped inside rontolisp, drawn in a browser. Every shape here comes from geom's own constructors — and the drilled block from geom:difference, a boundary-representation CSG subtraction — running as WebAssembly. This page is the twin of the macOS viewer scene: same model, same design, Metal there and WebGL here.

Drag to orbit, scroll to zoom. No triangle is touched per frame: each solid's model-space mesh went into a vertex buffer of its own once, and a frame sends one 4×4 matrix and one colour per solid.
