rontolisp agent skill

{{version}}

An agent skill for writing and running rontolisp programs. It assumes Common Lisp is already known and carries only the delta: which operators exist, which Common Lisp features are missing or partial, the rontolisp-only extensions, and how to run a program on each of the four backends. It is generated from the documentation on every deploy, so it never drifts from it.

Install (Claude Code)

mkdir -p ~/.claude/skills && \
  curl -sSL {{site-base}}/skill/{{skill-name}}-skill.tar.gz | tar xz -C ~/.claude/skills

Project-local instead: extract into .claude/skills in the repository.

Updating

The version bumps automatically whenever the documentation or the generator changes. Compare a local copy against {{site-base}}/skill/VERSION and re-run the install command when it has moved.
