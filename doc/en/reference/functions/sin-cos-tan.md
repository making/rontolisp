# sin cos tan

`(sin radians)` `(cos radians)` `(tan radians)`

The three basic trigonometric functions, each taking an angle in radians and returning a float. `sin` is the sine, `cos` the cosine, and `tan` the tangent. Available on the interpreter and JVM backends only (not WASM).

```lisp
(cos 0) ; => 1.0
```
