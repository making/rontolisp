# sinh cosh tanh

`(sinh number)` `(cosh number)` `(tanh number)`

The hyperbolic functions, each returning a float. `sinh` is the hyperbolic sine, `cosh` the hyperbolic cosine, and `tanh` the hyperbolic tangent. Available on the interpreter and JVM backends only (not WASM).

```lisp
(tanh 0) ; => 0.0
```
