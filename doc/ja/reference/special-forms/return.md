# return

`(return [value])`

最も内側を囲むループ(`do`、`dolist`、または `dotimes`)から非局所脱出を行い、そのループフォームを `value`(省略時は `nil`)に評価させます。`value` は脱出の前に評価されます。最も内側のループ境界を対象とするため、`return` はそのようなループの内部でのみ有効です。これは周囲のオペランドスタックが空である場所、たとえば `when`/`if` の分岐やループ本体の文において機能します。

```lisp
(dotimes (i 10) (when (= i 3) (return i))) ; => 3
```
