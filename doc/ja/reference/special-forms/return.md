# return

`(return [value])`

最も内側を囲むループ(`do`、`dolist`、`dotimes`、または `loop`)から非局所脱出を行い、そのループフォームを `value`(省略時は `nil`)に評価させます。`value` は脱出の前に評価されます。最も内側のループ境界を対象とするため、`return` はそのようなループの内部でのみ有効です。ループ本体であれば式の途中も含めてどこにでも書けます。その場合、囲んでいる式は評価を放棄されます。

```lisp
(dotimes (i 10) (when (= i 3) (return i))) ; => 3
```
