# quote

`(quote expr)` or `'expr`

`expr` を評価せずに返し、書かれたとおりのリテラルなデータ(シンボル、リスト、またはアトム)を生成します。これがリストリテラルやシンボルリテラルを作る方法です。リーダーマクロ `'expr` は `(quote expr)` の省略記法です。引数は決して評価されないため、`(quote (+ 1 2))` は `3` ではなく 3 要素のリストを返します。

```lisp
(quote (a b c)) ; => (A B C)
```

リテラルは `#n=` リーダーラベルの構造を保ちます。ラベルが共有するノードは 1 つのオブジェクトになり、自身のデータ内で参照するラベルはリスト、配列、構造体を通じて循環を閉じます。

```lisp
(let ((a '(#1=(x) #1#))) (eq (car a) (cadr a))) ; => T
(let ((a '#2=(x #2#))) (eq a (cadr a))) ; => T
```
