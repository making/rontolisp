# cond

`(cond (test body...)...)`

各節の `test` を順に評価し、最初に真 (非 nil) になったものについて、その節の本体の形式を評価して最後の値を返します。本体のない節は、その test 自身の値を返します。どの test も真でない場合、`cond` は nil を返します。最後の `(t body...)` 節はすべてを受けるデフォルトとして機能します。ネストした `if` 形式に展開されます。

```lisp
(let ((x 5)) (cond ((< x 0) 'neg) ((= x 0) 'zero) (t 'pos))) ; => POS
```
