# geom:mesh

`(geom:mesh solid)`

モデル空間でのソリッドの三角形。パックされた単精度配列で、1三角形あたり 18 float（3頂点分の位置＋法線）です。各面を扇状に三角形分割し、法線は Newell 法で求めます。剛体の三角形は変わらず変わるのは姿勢だけなので、1度だけ計算してソリッド上にキャッシュします。毎フレーム再分割するレンダラは、これを1度アップロードしてワールド変換をドローごとのユニフォームとして渡すレンダラより 42 倍遅くなります。 [ソリッドモデリングガイド](../../guides/solid-modeling.md)を参照。

```lisp
(length (geom:mesh (geom:box 1)))
; => 216
```
