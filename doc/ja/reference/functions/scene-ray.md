# scene:ray

`(scene:ray v x y)`

ビュー上の 1 点を通るワールド座標系の視線: `(始点 方向)` の 3 次元ベクトル 2 つで、方向は単位ベクトルです。`X` と `Y` はポイント単位のビュー座標 -- AppKit のものなので原点は左下、`+y` が上向きです。3-D ビューアにおけるピクセルとは本来これのことです。画面上の点はワールド中の**直線**を指すのであって、その直線のどの点を意図したのかはプログラム側の問題です。よくある場合には `scene:on-click` がこれを使って答えます。`scene` パッケージの一部です。`geom` ソリッド用の 3-D ビューアで、rontolisp 自身で `metal` と `appkit` の上に書かれ、初回使用時に読み込まれます。ディスプレイのある macOS 限定 (`java -jar`、`rontolisp` バイナリ、コンパイル済みの `.class` / `.jar`。`.wasm` は不可)。[ソリッドモデリングガイド](../../guides/solid-modeling.md)を参照。

```console
CL-USER> (scene:ray *v* 450.0 320.0)
(#(305.2 -412.7 690.0) #(-0.24 0.32 -0.55))
```
