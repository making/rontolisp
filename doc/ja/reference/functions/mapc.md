# mapc

`(mapc function list)`

`list` の各要素に対して副作用のために `function` を適用し、結果は捨てて元の `list` を返します。出力（表示など）の効果だけが目的のときに `mapcar` の代わりに使います。単一リストの形式のみ対応しています。

引数はリストでなければなりません（空リストの `nil` は受け付けられます）。文字列などリスト以外を渡すと、暗黙に何もしないのではなくエラーになります。文字列やベクタを写像するには `map` を使ってください。

```lisp
(mapc #'print '(1 2 3))
```

```
1
2
3
```
