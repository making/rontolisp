# mapc

`(mapc function list &rest more-lists)`

与えられたリストの要素に順に副作用のために `function` を適用し、結果は捨てて最初のリストを返します。出力（表示など）の効果だけが目的のときに `mapcar` の代わりに使います。単一のリストの場合、関数は 1 回の呼び出しにつき要素を 1 つ受け取ります。複数のリストを渡した場合は、各リストから 1 つずつ取り出した要素を並行して関数に渡し、最も短いリストの終端で反復を終了します。

各引数はリストでなければなりません（空リストの `nil` は受け付けられます）。文字列などリスト以外を渡すと、暗黙に何もしないのではなくエラーになります。文字列やベクタを写像するには `map` を使ってください。

```lisp
(mapc #'print '(1 2 3))
```

```
1
2
3
```

```lisp
(mapc (lambda (a b) (print (list a b))) '(1 2) '(3 4))
```

```
(1 3)
(2 4)
```
