# last

`(last list &optional n)`

`list` の最後のコンスセル、すなわち最終要素を含む 1 要素のリストを返します。空のリストでは `nil` を返します。オプションのカウント `n` を指定すると、代わりに最後の `n` 個のコンスを返します。`n` がリストの長さを超える場合はリスト全体を、`n` が 0 の場合は終端のアトム (真リストでは `nil`、ドットリストではその末尾) を返します。

```lisp
(last '(1 2 3)) ; => (3)
(last '(1 2 3) 2) ; => (2 3)
(last '(1 2 3) 0) ; => NIL
(last '(1 2 3) 5) ; => (1 2 3)
```
