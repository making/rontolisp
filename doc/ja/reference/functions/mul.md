# *

`(* &rest numbers)`

引数の積を返します。引数がない場合は `1` を返します。すべての引数が整数なら結果は整数、有理数が含まれる場合は厳密な値、いずれかの引数が浮動小数点数なら結果は浮動小数点数になります。整数結果は、どのバックエンドでもオーバーフロー時に多倍長整数へ昇格します。左から 1 組ずつ掛けるので、最初の浮動小数点数より前の引数は正確に掛け合わされ、その積だけが浮動小数点数になります: `(* 1/10 3 1.0)` は SBCL と同じく `0.3` です。

```lisp
(* 3 4) ; => 12
```

```lisp
(* 2.0 3.0) ; => 6.0
```
