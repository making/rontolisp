# maplist

`(maplist function list &rest more-lists)`

`mapcar` と同様ですが、`function` は与えられたリストの要素ではなく連続する cdr（末尾）に適用されます。まずリスト全体、次にその残り、というように最後の単一要素の末尾まで進みます。その結果からなる新しいリストを返します。複数のリストを渡した場合は、各リストから 1 つずつ取り出した末尾を並行して関数に渡し、最も短いリストの終端で反復を終了します。

各引数はリストでなければなりません（空リストの `nil` は受け付けられます）。文字列などリスト以外を渡すと、暗黙に `nil` を返すのではなくエラーになります。文字列やベクタを写像するには `map` を使ってください。

```lisp
(maplist #'identity '(1 2 3)) ; => ((1 2 3) (2 3) (3))
```

```lisp
(maplist #'list '(1 2) '(3 4)) ; => (((1 2) (3 4)) ((2) (4)))
```
