# max

`(max &rest numbers)`

引数のうち最大のものを返します。可変長引数を取り、少なくとも 1 つの引数が必要です。比較は数値で行われ、整数・有理数・浮動小数点数を自由に混在させられます。

左から `(a >= b) ? a : b` として畳み込みます（比較は IEEE のもの）。浮動小数点数が絡むときは 2 点を押さえてください。等しく比較される引数では**いちばん左**が残るので、`(max -0.0 0.0)` は `-0.0`、`(max 0.0 -0.0)` は `0.0` になります。`NaN` は順序付けできないため比較が偽になり、**右**の被演算子が選ばれます — `(max nan 1.0)` は `1.0`、`(max 1.0 nan)` は `NaN` です。どのバックエンドでも同じ答えになります。

```lisp
(max 5 2 8 1) ; => 8
```
