# linalg:det

`(linalg:det matrix)`

正方行列の行列式を返します。部分ピボット選択付きのガウスの消去法で浮動小数点で計算されます。正方でない引数はエラーを通知します。行列式が 0 であることは、[`linalg:inv`](linalg-inv.md) と [`linalg:solve`](linalg-solve.md) が失敗する条件です。浮動小数点計算のため、ほぼ特異な行列は厳密な `0` ではなく微小値を返すことがあります (下の例は消去が丸め誤差を生じないため厳密です)。

```lisp
(linalg:det #2A((1 2) (3 4))) ; => -2.0
(linalg:det #2A((1 2) (2 4))) ; => 0.0
```
