# sin cos tan

`(sin radians)` `(cos radians)` `(tan radians)`

3 つの基本的な三角関数で、それぞれラジアン単位の角度を取り浮動小数点数を返します。`sin` は正弦、`cos` は余弦、`tan` は正接です。インタプリタと JVM バックエンドは `Math.sin`/`Math.cos`/`Math.tan` で計算します。WASM バックエンドはソフトウェア近似（4 分円象限への Cody-Waite 引数縮約と Taylor 多項式）を使うため、結果の最下位桁がわずかに異なることがあり、非常に大きな引数（およそ `2^30` 超）では JVM が正確なままなのに対して精度が徐々に失われます。ゼロと象限のアンカーはどのバックエンドでも正確です: `(sin 0)` は `0.0`、`(cos 0)` は `1.0`、`(sin (/ pi 2))` は `1.0`、`(cos pi)` は `-1.0`。`NaN` や無限大の引数はどのバックエンドでも `NaN` になります。

```lisp
(cos 0) ; => 1.0
```
