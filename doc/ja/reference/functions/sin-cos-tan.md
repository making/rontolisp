# sin cos tan

`(sin radians)` `(cos radians)` `(tan radians)`

3 つの基本的な三角関数で、それぞれラジアン単位の角度を取り浮動小数点数を返します。`sin` は正弦、`cos` は余弦、`tan` は正接です。どのバックエンドも fdlibm で計算します（インタプリタと JVM では `StrictMath`、WASM では同じアルゴリズム）。大きな引数に対する正確な引数縮約も含まれるため、桁はどこでも一致します: `(sin 1e22)` は `-0.8522008497671888` です。ゼロと象限のアンカーはどのバックエンドでも正確です: `(sin 0)` は `0.0`、`(cos 0)` は `1.0`、`(sin (/ pi 2))` は `1.0`、`(cos pi)` は `-1.0`。`NaN` や無限大の引数はどのバックエンドでも `NaN` になります。

```lisp
(cos 0) ; => 1.0
```
