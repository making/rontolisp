# equalp

`(equalp x y)`

[`equal`](equal.md) と同様ですが、文字列と文字は大文字小文字を区別せず、数値は数値としての値 (`=`) で比較します。コンスセルは再帰的に比較されます。配列は次元が一致する場合に要素ごとに `equalp` で比較されます。構造体はスロットごとに `equalp` で比較され、CLOS インスタンスも同様です (Common Lisp ではこちらは同一性で比較します)。簡易版: ハッシュテーブルは `eql` にフォールバックします。

```lisp
(equalp #(1 "A") #(1 "a")) ; => T
```
