# linalg:/

`(linalg:/ a &rest arrays)`

`a` を残りの引数で左から順に要素ごとに除算し、新しい配列を返します。[`linalg:div`](linalg-div.md) の CL 演算子スペルであり、同じ numpy の規則でブロードキャストします。引数が 1 つの場合は CL の `/` と同じく逆数を返します。

```lisp
(linalg:/ #(1 2 3) 2)         ; => #d(0.5 1.0 1.5)
(linalg:/ #(12 12) 2 3)       ; => #d(2.0 2.0)
(linalg:/ #(1.0 2.0 4.0))     ; => #d(1.0 0.5 0.25)
```
