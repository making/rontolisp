# ffi:open

`(ffi:open &optional name-or-path)`

共有ライブラリを開き、整数のハンドルを返す。引数なし (あるいは `nil`)
ならプロセス自身のシンボルを指すハンドル `0` で、何もロードせずに使える。名前は
プラットフォームのローダが受け取るもの (`"libsqlite3.so.0"`、`"libm.dylib"`、
絶対パス) で、開けなければエラーを通知する。JVM 専用の `ffi` パッケージ ---
[上流の CFFI](../../guides/cffi.md) が乗っている外部関数プリミティブ --- の一部。
バインディングを書くならこれらの動詞ではなく `cffi:defcfun` を使う。

```lisp
(ffi:open)
; => 0
```

プロセスハンドルからは `strlen` や `getpid` などプロセスが既に持つシンボルがすべて見える。
