# union

`(union list1 list2 &key test key)`

両方を集合として扱い、`list1` または `list2` のいずれかに現れるすべての要素を含むリストを返します。既定では `eql` で比較します。省略可能な `:test` キーワードに関数指定子を渡すと別の比較を使え、省略可能な `:key` キーワードに渡したセレクタ関数は比較される両方の要素へ適用されます。結果の要素の順序は未規定です。

```lisp
(union '(1 2 3) '(2 3 4)) ; => (4 1 2 3)
```

```lisp
(union '("a" "b") '("b" "c") :test #'string=) ; => ("c" "a" "b")
```
