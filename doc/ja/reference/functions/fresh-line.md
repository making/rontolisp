# fresh-line

`(fresh-line &optional stream)`

`stream` (省略時は標準出力) がまだ行頭にない場合にのみ改行を書き込みます。桁 0 にあるストリームで空行を生むことはありません。改行を書いたときは `t` を、書かなかったときは nil を返します。二重改行のリスクなしに、後続の出力が独立した行から始まることを保証するために使います。

```lisp
(princ "a")
(fresh-line)
(princ "b")
```

```
a
b
```

ストリームは何を開いたかにかかわらず行頭から始まります。追記で開いたファイルは、ファイルが行の途中で終わっていても最初の `fresh-line` に nil を返します。文字を書くと位置が動き、`write-byte`、読み込み、`file-position` では動きません。そのためバイナリストリームは常に行頭にあります。
