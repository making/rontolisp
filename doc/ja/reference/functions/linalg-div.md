# linalg:div

`(linalg:div a b)`

`a` を `b` で要素ごとに除算し、新しい配列を返します。どちらの被演算子もスカラーにでき、その場合はもう一方の被演算子の shape にブロードキャストされます。両方が配列の場合は shape が一致していなければなりません (一致しない場合はエラーを通知します)。整数どうしの除算は浮動小数点数ではなく正確な比を生成します -- [`linalg:inv`](linalg-inv.md) と [`linalg:solve`](linalg-solve.md) を正確にしているのと同じ厳密算術です。

```lisp
(linalg:div #(1 2 3) 2) ; => #(1/2 1 3/2)
```
