# find-package

`(find-package designator)`

lite 版: rontolisp にパッケージオブジェクトはないため、返される「パッケージ」は大文字化された正規パッケージ名のキーワードで、未知のパッケージには `nil` を返します。`designator` はキーワード・文字列・シンボル・`nil`(名前が `"NIL"` のパッケージを指すので `nil` が返ります)です。パッケージ名は Common Lisp と同じく大文字小文字を区別します。

カレントパッケージが `designator` を[ローカルニックネーム](uiop-add-package-local-nickname.md)として持つときは、そのニックネームが指すパッケージを返します。これは呼び出しの実行時のカレントパッケージで決まるので、いずれかのパッケージがローカルニックネームとして持つリテラルの指定子は畳み込まれません。

それ以外のリテラルの指定子はコンパイル時に畳み込まれます。計算された指定子は、インタプリタでは生きたレジストリから、コンパイルバックエンドではコンパイル時に埋め込まれたプログラムのパッケージ表から解決されます -- そのため、コンパイル後に作られたパッケージはそこからは見えません。

```lisp
(list (find-package :cl) (find-package "nope")) ; => (:CL NIL)
```
