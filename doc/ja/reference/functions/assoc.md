# assoc

`(assoc key alist &key test)`

連想リスト(`(key . value)` ペアのリスト)を検索し、car が `key` に一致する最初のペアを返します。一致するものがなければ `nil` を返します。既定では `eql` で比較します。省略可能な `:test` キーワードに関数指定子を渡すと、別の比較関数を使えます(文字列キーには `#'equal` など)。返されるペアは連想リストと構造を共有します。キーではなく値で検索するには `rassoc` を使います。

```lisp
(assoc 'b '((a . 1) (b . 2))) ; => (b . 2)
```

```lisp
(assoc "b" '(("a" . 1) ("b" . 2)) :test #'equal) ; => ("b" . 2)
```
