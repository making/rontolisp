# geom:section

`(geom:section solid &key normal offset origin)`

平面が立体を切る断面ループ -- 断面図が 1 回の呼び出しで得られます。平面は `:normal` (軸キーワード、既定は `:z`。ベクトルも可) と、`:offset` (原点から法線方向への符号付き距離、既定 `0.0`) または `:origin` (平面上の 1 点) で指定します。各ループは**ワールド**座標の点を並べた rank-2 `(n 3)` packed float32 配列で、外側の境界は法線の正の側から見て反時計回り、穴は時計回りに巻かれます。平面が立体に当たらなければ `nil` を返します。トーラスを赤道で切ると、境界と穴の 2 ループになります。[ソリッドモデリングガイド](../../guides/solid-modeling.md)を参照。

```lisp
(first (geom:section (geom:box '(100 200 300))))
; => #f((-50.0 -100.0 0.0) (50.0 -100.0 0.0) (50.0 100.0 0.0) (-50.0 100.0 0.0))
```
