# =

`(= &rest numbers)`

すべての引数が数値的に等しければ `t` を、そうでなければ `nil` を返します。可変長引数を取り、型をまたいで数値として比較するため、整数とそれに等しい浮動小数点数や有理数は等しいと判定されます（`eql` とは異なります）。浮動小数点数と正確な数値の比較は正確な値で行われます。浮動小数点数はその正確な2進値で数えられるため、単にその浮動小数点数に丸められるだけの有理数は等しくなりません。引数が 1 つの場合は `t` を返します。

```lisp
(= 3 3 3) ; => T
(= 0.5 1/2) ; => T
(= 1.0 (+ 1 (/ 1 (ash 1 60)))) ; => NIL
```
