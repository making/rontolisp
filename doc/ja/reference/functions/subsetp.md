# subsetp

`(subsetp list1 list2 &key test key)`

`list1` と `list2` を集合として扱い、`list1` のすべての要素が `list2` のメンバーであれば真を返します。`list1` のいずれかの要素に対応するものがなければ、その時点で偽を返します。既定では `eql` で比較します。省略可能な `:test` キーワードに関数指定子を渡すと別の比較を使え、省略可能な `:key` キーワードに渡したセレクタ関数は比較される両方の要素へ適用されます。`list1` が空リストの場合は常に部分集合です。

```lisp
(subsetp '(1 2) '(1 2 3)) ; => T
```

```lisp
(subsetp '("a" "z") '("a" "b") :test #'string=) ; => NIL
```
