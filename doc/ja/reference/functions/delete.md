# delete

`(delete item list &key test key)`

`remove` の破壊的版です。`item` に一致するすべての要素を取り除いた `list` を返します。コピーするのではなくコンスセルをその場で変更します。既定では `eql` で比較します。省略可能な `:test` キーワードに関数指定子を渡すと別の比較を使え、省略可能な `:key` キーワードに渡したセレクタ関数は比較の前に各要素へ適用されます。リストの先頭が変わる可能性があるため、常に元の変数に頼らず戻り値を使ってください。

```lisp
(delete 2 '(1 2 3 2)) ; => (1 3)
```

```lisp
(delete "b" (list "a" "b" "c") :test #'string=) ; => ("a" "c")
```
