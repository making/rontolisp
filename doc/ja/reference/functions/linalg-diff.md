# linalg:diff

`(linalg:diff array &key n axis)`

`:axis` に沿った `:n` 階の離散差分を返します(numpy の `np.diff` 相当。`:axis` のデフォルトは最後の軸 `-1` で、負値は末尾から数えます)。各出力要素は `a[..., i+1, ...] - a[..., i, ...]` で、これを `:n` 回(デフォルト 1)適用するため、1 回ごとにその軸が 1 つ短くなります。任意のランクで動作し(行列はデフォルトでは各行内、`:axis 0` では各列に沿って差分)、結果は入力と同じ幅の新しいパック配列です(`#f` は `#f` のまま)。`:n 0` のときはパックされたコピーを返します。入力と同じ長さの微分近似が必要な場合は [`linalg:gradient`](linalg-gradient.md) を使ってください。

```lisp
(linalg:diff #(1 2 4 7 0)) ; => #d(1.0 2.0 3.0 -7.0)
```

```lisp
(linalg:diff #(1 2 4 7 0) :n 2) ; => #d(1.0 1.0 -10.0)
```

```lisp
(linalg:diff #2A((1 3 6) (0 5 6))) ; => #d((2.0 3.0) (5.0 1.0))
```

```lisp
(linalg:diff #2A((1 3 6) (0 5 6)) :axis 0) ; => #d((-1.0 2.0 0.0))
```
