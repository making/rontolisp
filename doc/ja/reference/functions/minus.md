# -

`(- number &rest numbers)`

引数が1つの場合はその符号を反転した値を返します。複数の場合は、最初の引数から残りの引数を左から右へ順に減算します。結果の型は通常の数値の伝播規則に従います。整数同士なら整数のまま、浮動小数点数が1つでも含まれると結果は浮動小数点数になり、有理数は厳密に保たれます。インタプリタとJVMでは、整数結果はオーバーフロー時に多倍長整数へ昇格します。WASMでは整数結果は符号付き64ビット範囲で正確で、それを超えるとラップします。

```lisp
(- 10 3) ; => 7
```

```lisp
(- 5) ; => -5
```
