# linalg:pad

`(linalg:pad array pads)`

ゼロパディング(numpy の `np.pad` のデフォルトである constant モード)です: `array` を内部にコピーし、それ以外を `0.0` で埋めた新しい配列を返します。`pads` は軸ごとの `(before after)` ペアのリスト -- または全軸の両側に適用される単一の非負整数です。結果は入力の要素幅を保ちます(`#f` 配列のパディングは `#f` になります)。

```lisp
(linalg:pad #(1 2) 1)                        ; => #d(0.0 1.0 2.0 0.0)
(linalg:pad #2A((1 2) (3 4)) '((0 0) (1 1))) ; => #d((0.0 1.0 2.0 0.0) (0.0 3.0 4.0 0.0))
```
