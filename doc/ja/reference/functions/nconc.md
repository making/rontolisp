# nconc

`(nconc &rest lists)`

各リスト引数について、空でないリストの最後の cdr を次の引数を指すように設定することでリスト引数を破壊的に連結し、最初の非 `nil` 引数を返します。新しいコンスセルは割り当てられないため、引数のリストはその場で変更されます。`(nconc)` は `nil` を返し、`(nconc x)` は `x` を返し、`nil` の引数はスキップされます。最後の引数は任意のオブジェクトでかまいません（コピーされることなく直前のリストの末尾に接続されます）。

```lisp
(nconc (list 1 2) (list 3 4) (list 5)) ; => (1 2 3 4 5)
```
