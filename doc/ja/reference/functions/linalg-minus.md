# linalg:-

`(linalg:- a &rest arrays)`

`a` から残りの引数を左から順に要素ごとに減算し、新しい配列を返します。[`linalg:sub`](linalg-sub.md) の CL 演算子スペルであり、同じ numpy の規則でブロードキャストします。引数が 1 つの場合は CL の `-` と同じく符号を反転します。

```lisp
(linalg:- #(5 5) 1)         ; => #d(4.0 4.0)
(linalg:- #(10 10) 1 2)     ; => #d(7.0 7.0)
(linalg:- #(5 5))           ; => #d(-5.0 -5.0)
```
