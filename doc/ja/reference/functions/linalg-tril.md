# linalg:tril

`(linalg:tril array &key k)`

`array` の下三角を返します。`k` 番目の対角線より**上**をすべて 0 にしたコピーです (numpy の `np.tril`)。比較を反転しただけで [`linalg:triu`](linalg-triu.md) と同じ規則に従います。`:k` のデフォルトは 0、rank は 2 以上、行列のスタックは最後の 2 軸がマスクされます。

```lisp
(linalg:tril #2A((1 2 3) (4 5 6) (7 8 9)))       ; => #d((1.0 0.0 0.0) (4.0 5.0 0.0) (7.0 8.0 9.0))
(linalg:tril #2A((1 2 3) (4 5 6) (7 8 9)) :k -1) ; => #d((0.0 0.0 0.0) (4.0 0.0 0.0) (7.0 8.0 0.0))
```
