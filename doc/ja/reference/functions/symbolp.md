# symbolp

`(symbolp object)`

`object` がシンボルであれば `t` を、そうでなければ `nil` を返します。`nil` とキーワードはシンボルである点に注意してください。そのため `(symbolp nil)` と `(symbolp :foo)` はいずれも `t` です。クォートされたシンボルと文字列リテラルはランタイム表現を共有しますが、先頭のクォート文字によって区別されるため、文字列はシンボルではありません。3 つすべてのバックエンドで動作します。

```lisp
(symbolp 'foo) ; => t
```

```lisp
(symbolp "foo") ; => nil
```
