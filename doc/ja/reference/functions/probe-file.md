# probe-file

`(probe-file pathname)`

ファイルが存在するかどうかを答えます。存在すればそのパス名を、存在しなければ `nil` を返します。これは何も開かずにこの問いに答える唯一のファイル操作であり、存在しないパスで失敗しない唯一の操作でもあります。`open`（したがって `with-open-file`）はインタプリタと JVM ではエラーを通知し、WASM では*トラップ*します。WASM のトラップは `handler-case` で捕捉できないため、`open` をくるむ方法は移植可能な代替にはなりません。4 つすべてのバックエンドで動作します。

rontolisp ではパス名はその名前文字列そのものなので、成功時に返される「真名 (truename)」は引数の文字列そのものです。どのバックエンドもシンボリックリンクを解決したり、パスを絶対パスにしたりはしません。パスの解釈は `open` と同じで、インタプリタと JVM ではプロセスの作業ディレクトリ基準、WASM では最初の preopen ディレクトリ基準です（`--dir` を付けて実行してください）。ディレクトリも存在するものとして扱われます。`uiop:file-exists-p` は同じ操作の ASDF/UIOP 側の名前です。

```console
(if (probe-file "config.lisp")
    (load "config.lisp")
    (print "no config"))
```

ここではファイルが存在する場合にのみ読み込みます。`probe-file` がなければ、ファイルが無い場合は `else` 側に進むのではなくプログラムが異常終了してしまいます。
