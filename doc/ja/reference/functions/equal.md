# equal

`(equal x y)`

構造的な等価性を判定します。コンスセルは car と cdr によって再帰的に比較され、文字列は 1 文字ずつ、ビットベクタは要素ごとに (フィルポインタまで) 比較されます。それ以外の配列、構造体、CLOS インスタンスは自分自身とだけ等しくなります。それ以外のものについては `eql` と同様に動作します。`t` または `nil` を返します。4 つすべてのバックエンドで動作します。

```lisp
(equal '(1 2 (3)) '(1 2 (3))) ; => T
```

```lisp
(equal "abc" "abc") ; => T
```

```lisp
(equal #*101 #*101) ; => T
```

```lisp
(equal #(1 0 1) #(1 0 1)) ; => NIL
```
