# linalg:mul

`(linalg:mul a b)`

`a` と `b` を要素ごとに乗算し (アダマール積)、新しい配列を返します -- これは行列積では *ありません*。行列積には [`linalg:matmul`](linalg-matmul.md) または [`linalg:dot`](linalg-dot.md) を使ってください。どちらの被演算子もスカラーにでき、その場合はもう一方の被演算子の shape にブロードキャストされます。両方が配列の場合は shape が一致していなければなりません (一致しない場合はエラーを通知します)。

```lisp
(linalg:mul 2 #2A((1 2) (3 4))) ; => #f((2.0 4.0) (6.0 8.0))
(linalg:mul #2A((1 2) (3 4))
            #2A((5 6) (7 8)))   ; => #f((5.0 12.0) (21.0 32.0))
```
