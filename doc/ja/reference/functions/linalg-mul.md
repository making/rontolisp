# linalg:mul

`(linalg:mul a b)`

`a` と `b` を要素ごとに乗算し (アダマール積)、新しい配列を返します -- これは行列積では *ありません*。行列積には [`linalg:matmul`](linalg-matmul.md) または [`linalg:dot`](linalg-dot.md) を使ってください。被演算子は [`linalg:add`](linalg-add.md) に記載のとおり numpy の規則でブロードキャストされます: スカラーはもう一方の被演算子の shape にブロードキャストされ、shape の異なる 2 つの配列は末尾の軸から揃えて、揃えた各軸の長さが等しいかどちらかが 1 のときにブロードキャストされます。

```lisp
(linalg:mul 2 #2A((1 2) (3 4))) ; => #d((2.0 4.0) (6.0 8.0))
(linalg:mul #2A((1 2) (3 4))
            #2A((5 6) (7 8)))   ; => #d((5.0 12.0) (21.0 32.0))
(linalg:mul #2A((1 2) (3 4))
            #(10 20))           ; => #d((10.0 40.0) (30.0 80.0))
```
