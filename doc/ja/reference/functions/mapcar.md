# mapcar

`(mapcar function list)`

`list` の各要素に順に `function` を適用し、その結果からなる新しいリストを返します。関数は 1 回の呼び出しにつき要素を 1 つ受け取ります。rontolisp は単一リストの形式のみをサポートしており、複数のリストを並行してマッピングすることはできません。

引数はリストでなければなりません（空リストの `nil` は受け付けられます）。文字列などリスト以外を渡すと、暗黙に `nil` を返すのではなくエラーになります。文字列やベクタを写像するには `map` を使ってください。

```lisp
(mapcar #'car '((1 2) (3 4))) ; => (1 3)
```
