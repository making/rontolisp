# mapcar

`(mapcar function list &rest more-lists)`

与えられたリストの要素に順に `function` を適用し、その結果からなる新しいリストを返します。単一のリストの場合、関数は 1 回の呼び出しにつき要素を 1 つ受け取ります。複数のリストを渡した場合は、各リストから 1 つずつ取り出した要素を並行して関数に渡し、最も短いリストの終端で反復を終了します。

各引数はリストでなければなりません（空リストの `nil` は受け付けられます）。文字列などリスト以外を渡すと、暗黙に `nil` を返すのではなくエラーになります。文字列やベクタを写像するには `map` を使ってください。

```lisp
(mapcar #'car '((1 2) (3 4))) ; => (1 3)
```

```lisp
(mapcar #'+ '(1 2 3 4) '(10 20 30 40)) ; => (11 22 33 44)
```
