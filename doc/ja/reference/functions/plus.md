# +

`(+ &rest numbers)`

引数の合計を返します。引数がない場合は `0` を返します。すべての引数が整数のときは結果は整数、ratio が関与するときは ratio、いずれかの引数が浮動小数点数のときは浮動小数点数になります（汚染）。整数の結果は、どのバックエンドでもオーバーフロー時に多倍長整数へ昇格します。複素数の引数があっても左から 1 組ずつ足すので、正確な段階は後に続く浮動小数点数に関係なく正確なままです: 正確な複素数 `z` について `(+ z (- z) 1.5)` は SBCL と同じく `1.5` です。

```lisp
(+ 1 2 3) ; => 6
```

```lisp
(+ 1.5 2.5) ; => 4.0
```
