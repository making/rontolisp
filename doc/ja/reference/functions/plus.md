# +

`(+ &rest numbers)`

引数の合計を返します。引数がない場合は `0` を返します。すべての引数が整数のときは結果は整数、ratio が関与するときは ratio、いずれかの引数が浮動小数点数のときは浮動小数点数になります（汚染）。整数の結果は、どのバックエンドでもオーバーフロー時に多倍長整数へ昇格します。左から 1 組ずつ足すので、最初の浮動小数点数より前の引数は正確に足し合わされ、その和だけが浮動小数点数になります: `(+ 1/10 1/5 0.0)` は SBCL と同じく `0.3` で、各引数を先に変換したときの `0.30000000000000004` ではありません。複素数の引数も同じく畳み込みます: 正確な複素数 `z` について `(+ z (- z) 1.5)` は `1.5` です。

```lisp
(+ 1 2 3) ; => 6
```

```lisp
(+ 1.5 2.5) ; => 4.0
```
