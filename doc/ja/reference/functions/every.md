# every

`(every predicate &rest sequences)`

各シーケンスの要素を 1 つずつ `predicate` に適用し、すべての呼び出しが非 nil なら `t` を返し、1 つでも失敗した時点で `nil` を返します (最初の失敗でテストを打ち切ります)。各シーケンスにはリストまたは文字列 (要素は文字) を渡せます。シーケンスを複数渡した場合、述語はシーケンスごとに 1 つずつ引数を受け取り、最も短いシーケンスが尽きた時点で走査を終えます。空のシーケンスでは `t` を返します。

```lisp
(every #'evenp '(2 4 6)) ; => T
```

```lisp
(every #'digit-char-p "123") ; => T
```

```lisp
(every #'< '(1 2) '(3 4)) ; => T
```
