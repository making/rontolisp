# apply

`(apply function &rest args)`

先頭の引数を、最後の引数（リストでなければなりません）の要素の前に連結して `function` を呼び出し、その結果を返します。`funcall` と同様に、`function` には関数値（`#'f` や `lambda`）またはクォートされたシンボル指定子を渡せます。`(apply #'+ 1 2 '(3 4))` は `(funcall #'+ 1 2 3 4)` と等価です。`(apply #'+ '(1 2 3))` のように展開するリストだけを渡すこともできます。

```lisp
(apply #'+ 1 2 '(3 4)) ; => 10
```
