# sinh cosh tanh

`(sinh number)` `(cosh number)` `(tanh number)`

双曲線関数で、それぞれ浮動小数点数を返します。`sinh` は双曲線正弦、`cosh` は双曲線余弦、`tanh` は双曲線正接です。3 つともすべてのバックエンドで動きます。インタプリタと JVM は `Math.sinh`/`Math.cosh`/`Math.tanh` を使い、WASM バックエンドは 3 つともソフトウェア近似の `exp` から導出するため、最下位桁でわずかに結果が異なる場合があります(`|x|` が ~20 までで相対誤差 ~1e-7、それ以上ではソフトウェア `exp` 自体と同様に精度が低下します。`sinh` は `|x| = 0.25` 未満で Taylor 級数に切り替わるため、微小な引数でも正確です)。`(sinh 0)` は正確に `0.0`、`(cosh 0)` は正確に `1.0` で、これはどのバックエンドでも同じです。

```lisp
(tanh 0) ; => 0.0
```
