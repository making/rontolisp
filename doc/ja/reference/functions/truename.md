# truename

`(truename pathname)`

ファイルが存在すればそのパス名を返し、存在しなければ `file-error` を通知します。この通知こそが
要点です。`(ignore-errors (truename path))` は「あればそのパス、無ければ `nil`」を表す
Common Lisp の定型句であり、ライブラリは任意指定のファイルやディレクトリの有無を調べる
のにこれを使います。

成功時の値は、パスに含まれるシンボリックリンクをすべて解決し、`.` と `..` を取り除いた
絶対パスです。リンクの後の `..` は、リンクの指す先から数えます。相対パスは SBCL と同じく、
まず `*default-pathname-defaults*` とマージし、作業ディレクトリの下に置きます。`/w` で
実行し、`d` が `x/y` へのリンクなら、`(truename "d/../f.txt")` は `#P"/w/x/f.txt"` です。
作業ディレクトリを持たないプログラム（最初のプリオープンディレクトリにホストが相対パスの
名前を付けた WASM モジュール。`wasmtime run --dir .` がそうです）では答えは相対パスのまま
`#P"x/f.txt"` です（詳細は [`probe-file`](probe-file.md)）。ディレクトリは綴りによらず（末尾に `/` の付いた）ディレクトリ形式で返り、指す先が存在しない
リンクは SBCL と同じくリンク自身を返します。条件を通知させずに存在だけを調べたい場合は
[`probe-file`](probe-file.md) を使ってください。同じパス名を返し、通知の代わりに `nil` を
返します。ファイルストリームも受け付け、開いたファイルの truename を返します
([`pathname`](pathname.md))。

2 つの WASM バックエンドでは、モジュールがプリオープンされたディレクトリを通して読める
リンクだけを解決し、絶対パスを指すリンクはたどりません（WASI ホストが拒否します）。
そのようなパスは存在しないものとして扱われます（詳細は [`probe-file`](probe-file.md)）。

```lisp
(ignore-errors (truename "definitely-missing.txt"))   ; => NIL
```

## バックエンドサポート

4 つすべてのバックエンドで動作します。リンク 1 つを読むバックエンドごとの基本操作
（2 つの WASM バックエンドでは WASI インポートの `path_readlink`、`--component` では
`wasi:filesystem` の `readlink-at` を通す）の上に書かれた rontolisp ソースによる 1 つの
定義があり、参照されたときにプログラムへ差し込まれます。
