# log

`(log number)`

`number` の自然対数 (底 e) を浮動小数点数として返します。1 引数形式のみがサポートされ、任意の底を指定する `(log number base)` 形式はありません。インタプリタと JVM バックエンドは `Math.log` で計算します。WASM バックエンドはソフトウェア近似（指数部の抽出と多項式級数）を使うため、最下位桁でわずかに結果が異なる場合があります。IEEE の端値はどこでも一致します: `(log 0.0)` は `-Infinity`、負の引数は `NaN` です。

```lisp
(log 1) ; => 0.0
```
