# eval

`(eval form)`

フォーム（通常は `read`、`read-from-string`、またはクォートによって生成されたリスト）をグローバル環境で評価し、その結果を返します。3 つすべてのバックエンドで動作します。インタプリタは直接評価し、JVM および WASM コンパイラはコンパイル済みの値表現を共有する小さなランタイムの木探索インタプリタを出力します。コンパイル済みプログラムが定義したトップレベルのグローバル変数は eval 環境にミラーされるため、eval された式からそれらを参照できます。

```lisp
(eval '(+ 1 2)) ; => 3
```

フォームをクォートすると、`eval` が実行するまで評価されないままになります。`(eval (read-from-string "(* 6 7)"))` は `42` を返します。
