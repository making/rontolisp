# eql

`(eql x y)`

型と値が同じ 2 つの数値、等しい 2 つの文字、それ以外では同一のオブジェクトに対して `t` を返します。ここでは [`eq`](eq.md) と同じ述語です。CL は `eq` が数値を同一性で比較することを許しているため、数値の比較の移植性のある書き方は `eql` です。型が異なる数値は `eql` になりません（`(eql 3 3.0)` は `nil`）。コンスセルの中を辿ることも、文字列の内容を比較することもしません。構造的な比較には `equal` を使ってください。3 つすべてのバックエンドで動作します。

```lisp
(eql 1.5 1.5) ; => T
```

```lisp
(eql 3 3.0) ; => NIL
```
