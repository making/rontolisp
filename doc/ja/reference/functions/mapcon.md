# mapcon

`(mapcon function list &rest more-lists)`

`maplist` と同様に `function` は与えられたリストの連続する末尾（tail）に適用されますが、結果のリストは 1 つに連結されます（`mapcan` の末尾を辿る版です）。各部分は `append` で結合され、リストでない部分は `type-error` を通知します。複数のリストを渡した場合は、各リストから 1 つずつ取り出した末尾を並行して関数に渡し、最も短いリストの終端で反復を終了します。

各引数はリストでなければなりません（空リストの `nil` は受け付けられます）。文字列などリスト以外や、走査が末尾まで達したドットリストを渡すと、暗黙に `nil` を返すのではなく `type-error` を通知します。文字列やベクタを写像するには `map` を使ってください。

```lisp
(mapcon (lambda (x) (list (car x))) '(1 2 3)) ; => (1 2 3)
```

```lisp
(mapcon #'list '(1 2) '(3 4)) ; => ((1 2) (3 4) (2) (4))
```
