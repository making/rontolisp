# eq

`(eq x y)`

オブジェクトの同一性を判定し、`t` または `nil` を返します。同じ値のシンボルや小さな整数は同一のオブジェクトなので `eq` で等しくなりますが、浮動小数点数や比はそれぞれ別個のボックス化オブジェクトであり、数値的に等しくても決して `eq` にはなりません。コンスセルは参照で比較されます。数値や構造を値で比較するには `eql` や `equal` を使ってください。3 つすべてのバックエンドで動作します。

```lisp
(eq 'foo 'foo) ; => T
```

```lisp
(eq 1.5 1.5) ; => NIL
```
