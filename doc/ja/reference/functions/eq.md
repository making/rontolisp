# eq

`(eq x y)`

オブジェクトの同一性を判定し、`t` または `nil` を返します。シンボルは同一性で比較されます。コンスセルと文字列は参照で比較されるため、同じ文字を持つ別個の 2 つの文字列は `eq` になりません(プログラム中の等しい文字列リテラル同士は 1 つのオブジェクトです)。数値と文字は値と別の同一性を持ちません。CL は数値に対する `eq` を処理系依存としており、ここでは [`eql`](eql.md) と完全に同じです。型と値が同じ 2 つの数値は浮動小数点数や比も含めて `eq` になるため、浮動小数点数はどのように格納されても常に自身と `eq` です。構造の比較には `equal` を使ってください。3 つすべてのバックエンドで動作します。

```lisp
(eq 'foo 'foo) ; => T
```

```lisp
(eq 1.5 1.5) ; => T
```
