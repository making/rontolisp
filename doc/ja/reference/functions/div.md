# /

`(/ number &rest numbers)`

最初の引数を残りの引数で左から右へ順に割ります。引数が 1 つの場合はその逆数を返します。整数の除算は正確で、結果が整数にならない場合は切り捨てずに約分した比として返し、割り切れる場合は整数を返します。いずれかの引数が浮動小数点数であれば結果は浮動小数点数になります。正確な 0 での除算は `division-by-zero` を通知します。浮動小数点数の被演算数を含む除算は IEEE 754 に従うので、`(/ 1.5 0)` と `(/ 1 0.0)` は無限大、`(/ 0.0 0)` は NaN です。

浮動小数点数の複素数の商は Smith の形で計算します -- 除数の大きい方の成分を基準に畳み込みます -- そのため実数の除数では各成分がそれぞれ独立に割られ (`(/ #c(1d0 2d0) 3d0)` の丸めは成分あたり 3 回ではなく 1 回です)、被演算数自体が表現できる範囲では途中の値が溢れることもありません: `(/ #c(1d200 1d200) #c(1d200 1d200))` は `#C(1.0 0.0)` です。正確な成分は正確な有理数のまま計算され、正確な 0 での除算は実数の場合と同じ 0 除算エラーを通知します。

```lisp
(/ 1 2) ; => 1/2
```

```lisp
(/ 10 2) ; => 5
```
