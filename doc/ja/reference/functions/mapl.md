# mapl

`(mapl function list &rest more-lists)`

[`maplist`](maplist.md) と同様ですが、`function` は与えられたリストの連続する cdr (末尾リスト) に副作用のためだけに適用され、結果のリストではなく最初のリストを返します。複数のリストを渡した場合は、各リストから 1 つずつ取り出した末尾を並行して関数に渡し、最も短いリストの終端で反復を終了します。

各引数はリストでなければなりません (空リスト `nil` は受理されます)。文字列などの非リストを渡すとエラーがシグナルされます。

```lisp
(mapl #'identity '(1 2 3)) ; => (1 2 3)
```

```lisp
(mapl (lambda (a b) (print (list a b))) '(1 2) '(3 4))
```

```
((1 2) (3 4))
((2) (4))
```
