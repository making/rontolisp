# adjoin

`(adjoin item list &key test key)`

`item` がすでにメンバーである場合は `list` をそのまま返し、そうでなければ `item` を先頭に追加した新しいリストを返します。既定では `eql` で比較します。省略可能な `:test` キーワードに関数指定子を渡すと別の比較を使え、省略可能な `:key` キーワードに渡したセレクタ関数は `item` とリストの各要素の両方へ適用されます (先頭に追加される `item` は元のままです)。重複を作らずに集合へ要素を追加する非破壊的な方法です。

```lisp
(adjoin 1 '(2 3)) ; => (1 2 3)
```

```lisp
(adjoin "a" '("a" "b") :test #'string=) ; => ("a" "b")
```
