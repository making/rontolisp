# linalg:+

`(linalg:+ &rest arrays)`

引数を左から順に要素ごとに加算し、新しい配列を返します。[`linalg:add`](linalg-add.md) の CL 演算子スペルであり、各ステップは同じ numpy の規則でブロードキャストするため、スカラーと shape の合う配列を自由に混ぜられます。引数がない場合は `0`、引数が 1 つの場合はその引数をそのまま返します。

```lisp
(linalg:+ #(1 2 3) 10)             ; => #d(11.0 12.0 13.0)
(linalg:+ #(1 2) #(3 4) #(10 10))  ; => #d(14.0 16.0)
(linalg:+)                         ; => 0
```
