# rem

`(rem number divisor)`

`number` を `divisor` で切り捨て除算 (truncated division) したときの剰余を返します。そのため 0 でない結果は常に被除数の符号を取ります。これは `truncate` の対になる関数です。結果を除数の符号に合わせたい場合は代わりに `mod` を使用してください。

結果が **0** の浮動小数点数になる場合は `0.0` であり、`-0.0` になるのは被除数が `-0.0` かつ除数が正のときだけです。`rem` は `truncate` の第 2 返り値、すなわち商を厳密な整数とした `number - divisor*quotient` なので、0 の符号は被除数から複写されるのではなく、この減算の結果として決まります。

```lisp
(rem 13 4) ; => 1
```

```lisp
(rem -13 4) ; => -1
```

```lisp
(rem 7/2 3) ; => 1/2
```

```lisp
(rem -4.0 2.0) ; => 0.0
```

```lisp
(rem -0.0 2.0) ; => -0.0
```
