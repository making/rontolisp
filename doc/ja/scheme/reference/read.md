# read

`(read)`

現在の入力ポートから次のデータを読んで返します（シンボル、数、文字列、文字、リスト、ベクタ、クォートされた形式）。入力の終わりではファイル終端オブジェクトを返します。ポート引数はありません。ソース中でリーダーが拒否する構文はここでも拒否されます（`|...|` 識別子、`+inf.0`/`+nan.0`、バイトベクタ、`[`/`]`/`{`/`}`）。不完全または不正なデータは、`read-error?` が `#t` を返すエラーを発生させます。

```stdin
(1 "two" #\3) foo
```

```scheme
(write (read))
(newline)
(write (read))
(newline)
(write (read))
(newline)
```

```
(1 "two" #\3)
foo
#<eof>
```
