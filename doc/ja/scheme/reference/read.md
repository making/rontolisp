# read

`(read [port])`

現在の入力ポートから次のデータを読んで返します（シンボル、数、文字列、文字、リスト、ベクタ、クォートされた形式）。入力の終わりではファイル終端オブジェクトを返します。`port` を渡すとそのポートから読みます。`port` は開いているテキスト入力ポートでなければなりません。ソース中でリーダーが拒否する構文はここでも拒否されます（`|...|` 識別子、`+inf.0`/`+nan.0`、`[`/`]`/`{`/`}`）。`#u8(...)` のバイトベクタは読めます。不完全または不正なデータは、`read-error?` が `#t` を返すエラーを発生させます。

```stdin
(1 "two" #\3) foo
```

```scheme
(write (read))
(newline)
(write (read))
(newline)
(write (read))
(newline)
```

```
(1 "two" #\3)
foo
#<eof>
```

```scheme
(read (open-input-string "(a . b) c")) ; => (a . b)
```
