# eq?

`(eq? obj1 obj2)`

`obj1` と `obj2` が同一のオブジェクトなら `#t` を返します。シンボル、`'()`、真偽値、文字、正確な整数は等しければ常に `eq?` です。浮動小数点数と正確な分数は別々のオブジェクトなので `(eq? 1.5 1.5)` は `#f` になります。数値には `eqv?` を使ってください。ペア、文字列、ベクタは同じオブジェクトのときだけ `eq?` です。

```scheme
(eq? 'a 'a) ; => #t
(eq? (list 1) (list 1)) ; => #f
(eq? 1.5 1.5) ; => #f
```
