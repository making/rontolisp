# eq?

`(eq? obj1 obj2)`

`obj1` と `obj2` が同一のオブジェクトなら `#t` を返します。シンボル、`'()`、真偽値は等しければ常に `eq?` です。R7RS は数値と文字に対する `eq?` を規定していません。ここでは `eqv?` と完全に同じなので `(eq? 1.5 1.5)` は `#t` になり、浮動小数点数は常に自身と `eq?` です。移植性のある書き方は `eqv?` です。ペア、文字列、ベクタは同じオブジェクトのときだけ `eq?` です。

```scheme
(eq? 'a 'a) ; => #t
(eq? (list 1) (list 1)) ; => #f
(eq? 1.5 1.5) ; => #t
```
