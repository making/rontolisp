# eqv?

`(eqv? obj1 obj2)`

`eq?` と同様ですが、正確性と値が同じ数値は等価とみなすので `(eqv? 1.5 1.5)` は `#t` です。一方 `(eqv? 2 2.0)` は正確性が異なるため `#f` です。`0.0` と `-0.0` は `eqv?` ではありません。ペア、文字列、ベクタ、手続きは同一性で比較します。1 つのプログラム内の同じ内容の文字列リテラルは同じオブジェクトになることがあり、これは R7RS が認めています。

```scheme
(eqv? 1.5 1.5) ; => #t
(eqv? 2 2.0) ; => #f
(eqv? (string #\a) (string #\a)) ; => #f
```
