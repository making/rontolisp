# quasiquote

`(quasiquote template)` `` `template ``

`template` からリストまたはベクタを組み立てます。`unquote`（`,`）で印を付けた部分は評価され、`unquote-splicing`（`,@`）で印を付けた部分は評価されて展開され、それ以外はそのまま使われます。入れ子は R7RS どおりに数えられ、入れ子のテンプレートでは最も内側の段だけが評価されます。

```scheme
`(1 ,(+ 1 1) 3) ; => (1 2 3)
`#(1 ,(* 2 3)) ; => #(1 6)
`(a . ,(+ 1 2)) ; => (a . 3)
```
