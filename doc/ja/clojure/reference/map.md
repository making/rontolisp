# map

`(map f coll)`

`coll` の seq ビューの各要素へ `f` を適用した結果のリストを返します。リストはそのまま通り、それ以外のコレクションはまず型変換されるため、ベクター・文字列・マップ（エントリのベクター）・セットのすべてが動きます。空の結果は `nil` です。値としてはラムダなので、`map` は `inc` 型の裸の名前を取ります。

```clojure
(println (map inc '(1 2)))      ; (2 3)
(println (map #(inc %) [1 2 3])) ; (2 3 4)
(println (map :k [{:k 1} {:k 2}])) ; (1 2)
```
