# +

`(+ x...)`

引数を左から右へ足し合わせます。`(+)` は `0` です。正確性は引数に従います。整数と有理数は正確なまま、double が入ると結果も double になります。`*unchecked-math*` が真値（`true` または `:warn-on-boxed`）の間、64 ビット整数の和は桁上げせず 2^64 で折り返します。boxed-math 警告は出ません。値としてはフラグによらず通常の動詞が使われます。

```clojure
(println (+ 1 2 3)) ; 6
(println (+ 1/2 1/3)) ; 5/6
(println (+)) ; 0
```
