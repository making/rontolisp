# set

`(set coll)`

`coll` の要素のセットを返します。リスト・ベクター・マップ（そのエントリのベクター）・セットは、各メンバーをそのものの下に格納する新しい `equal` 表へ重複を除いて入ります。`nil` の `set` は空セットです。要素は `equal` 表のキーと同じく比較されるため、ベクターは同一性で重複除去されます。

仕様との差異: セットリテラルの要素の重複は読み取り時に綴りとして拒否されますが、実行時に届いた equal な要素は黙って重複除去されます。

```clojure
(println (count (set [1 2 2 3])))     ; 3
(println (contains? (set [1 2 2 3]) 2)) ; true
(println (count (set nil)))           ; 0
```
