`(->> expr step...)`

`expr` を各ステップへ通します。リストのステップには値を最後の要素として挿入し、裸の名前やキーワードは値を引数に呼ばれ、最後のステップの値が結果になります。スレッド化した呼び出しへ datums として書き換えて低レベル化されます。コレクションリテラルに対するステップはシグナルを上げます（ここではコレクションは関数ではありません）。

```clojure
(println (->> 5 inc inc))            ; 7
(println (->> [1 2] (map inc)))      ; (2 3)
(println (->> [3 1] (apply max)))    ; 3
```
