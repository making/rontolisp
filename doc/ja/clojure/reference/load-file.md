# load-file

`(load-file path)`

リテラルの `path` のファイルをその呼び出しの場所で読み下し、最後の形の値を返す。[load-string](load-string.md) と同じ。`path` は Clojure と同じくファイルシステムのパスで、呼び出しがどの名前空間にあっても作業ディレクトリから相対に探す。ファイルが切り替えた名前空間はその読み込みだけのもの。求まる形のパスは、インタプリタでは呼び出しの実行時に読み下される（インタプリタはプログラムの lower を実行中も保持する）。コンパイル済みプログラムは lower の仕組みを持たないため、実行時に拒否される。値としては 1 引数を取る。

```console
clojure> (load-file "helper.clj")
41
```
