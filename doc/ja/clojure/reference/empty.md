# empty

`(empty coll)`

`clojure.core/empty`: `coll` と同じ種類の空のコレクションを返します。ベクター・マップ・
セットは新しい空のものを、ソート済みのマップ・セットは同じ比較関数の空のものを返し、
いずれも `coll` のメタデータを引き継ぎます。文字列・`nil`・コレクションでない値は
`nil` を返します。レコードはシグナルを上げます（`Can't create empty: ...`）。値としては
1引数の関数です。

仕様との差異: リスト・遅延シーケンス・シーケンスは、オラクルが `()` を返すところで `nil` を返し
（`rest`/`next` と同じ、空を `nil` とする扱い）、メタデータも持ちません。マップエントリは
オラクルが `nil` を返すところで `[]` を返します。

```clojure
(prn (empty [1 2]) (empty {:a 1}) (empty "ab")) ; [] {} nil
(prn (conj (empty (sorted-set-by > 1 2)) 1 3 2)) ; #{3 2 1}
```
