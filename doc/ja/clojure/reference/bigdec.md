# bigdec

`(bigdec x)`

整数はそのまま、doubleは表示される最短の10進表現の厳密な有理数（`(bigdec 0.1)` は `1/10`）、比は10進展開が有限のときだけ（`(bigdec 1/3)` はオラクル同様シグナル）、10進文字列（`"1.5"`、`"1e3"`）は解析した値を返します。NaN・無限大・`nil`・文字はシグナルします。decimal型はないため結果は通常の有理数で、そのように表示されます（オラクルの `1.5M` は `3/2`）。`(double (bigdec "1.5"))` は `1.5` です。値としては1引数の関数です。

```clojure
(println (bigdec 0.1) (double (bigdec "1.5"))) ; 1/10 1.5
```
