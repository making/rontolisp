# pvalues

`(pvalues expr...)`

各式を呼び出しスレッドで順に評価し、値の seq を返します。どのバックエンド
にもスレッドプールがありません（[`pmap`](pmap.md) が `map` であるのと
同じです）。そのため評価は逐次です。throw した式で後の式は止まり、
スレッドローカルへの書き込みはオラクルのプールスレッドが拒否する箇所でも
見えたままになります。空の `pvalues` は `nil` を返します（オラクルの空の
lazy seq は `()` と印字されます）。値としてはマクロのままです（`(def x
pvalues)` は拒否されます）。マクロの var 値は後回しのため、そのピン留めも
そちらに残ります。

```clojure
(println (pvalues 1 (+ 1 2))) ; (1 3)
```
