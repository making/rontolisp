# pvalues

`(pvalues expr...)`

インタプリタと JVM では式ごとに一つの future を走らせます。各式が作成時の束縛を
携えて自分のスレッドで走り、順に deref するので、枝は重なりながら値はオラクル
と同じ順で答えます。失敗は他の枝の開始後に deref の順で表面化し、オラクルの
`ExecutionException` で包まれます。スレッドのない WASM 層では各式を呼び出し
スレッドで順に評価します。印字される seq は同じです。空の `pvalues` は `nil` を返します（オラクルの空の
lazy seq は `()` と印字されます）。値としては実行時の一回展開の委譲を答えます（[bound-fn](bound-fn.md) を
見てください）。オラクルはむき出しのマクロ名を値位置でコンパイル時に
拒否します。

```clojure
(println (pvalues 1 (+ 1 2))) ; (1 3)
```
