# bigint

`(bigint x)`

数値（10 進数を含む）を0方向に切り捨てた整数、または10進文字列を解析した整数を返します。NaN・無限大・`nil`・文字・不正な文字列はオラクル同様シグナルします。すべての整数は任意精度です。long の範囲を超える整数はオラクルと同じく `N` 付きで印字され、範囲内の整数は通常の整数として `N` なしで印字されます（オラクルの `BigInt` は `1N`）。値としては1引数の関数です。

```clojure
(println (bigint 1.5) (bigint 7/2) (bigint "123") (bigint 1e20)) ; 1 3 123 100000000000000000000N
```
