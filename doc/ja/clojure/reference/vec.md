# vec

`(vec coll)`

コレクションの要素の上にベクターを組み立てて返します。リストは要素ごとにそのまま通り、文字列は文字のベクターになり、マップはエントリごとに 1 つの 2 要素ベクターを、セットは要素ごとに 1 つを与えます。`(vec nil)` は `[]` です。遅延入力は完全に実現します（無限入力はオラクル同様止まりません）。コレクションでない値（数値、キーワード、シンボル、関数、マッチャーなど）はオラクルと同じく `RuntimeException` をシグナルします。

値としては 1 引数のラムダです。

```clojure
(println (vec '(1 2)))      ; [1 2]
(println (vec "ab"))        ; [a b]
(println (vec nil))         ; []
(println (vec (map inc [1 2]))) ; [2 3]
(println (map vec (list [1] '(2)))) ; ([1] [2])
```
