# format

`(format fmt args...)`

Java 形式の書式文字列を描画して返します。`%s` は `str` 同様に変換し（`nil` は
`String/valueOf` 同様 `"null"`）、`%b` は真偽値綴り、`%d`・`%x`・`%X`・`%o` は整数
（検査付き）、`%c` は文字（検査付き）、`%f` は任意の幅・精度付き浮動小数点、`%%` と
`%n` はそれ自体です。指示子は lowering 時に翻訳するため書式文字列はリテラル必須です。
フラグ・`%e`・`%g`・日時・ハッシュ等は誤答の代わりに名前付きで拒否されます。

```clojure
(println (format "%s=%d" :a 5)) ; :a=5
(println (format "%5s|%.2f" "ab" 3.14159)) ;    ab|3.14
```
