# load-string

`(load-string s)`

リテラルの文字列 `s` をその呼び出しの場所で読み下す。今の名前空間で。定義はファイルと同じく先に宣言される。最後の形の値を返す（空文字列は `nil`）。oracle と同じ。文字列が切り替えた名前空間はその読み込みだけのもので、oracle の `Compiler/load` と同じく `*ns*` を束縛して読み込む。求まる形の文字列は、インタプリタでは呼び出しの実行時に `*ns*` の名前空間で読み下される。コンパイル済みプログラムは lower の仕組みを持たないため、実行時に拒否される。値としては 1 引数を取る。

```clojure
(println (load-string "(+ 1 2)")) ; 3
```
