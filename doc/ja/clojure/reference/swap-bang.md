# swap!

`(swap! atom f x...)`

アトムの値と追加の引数へ `f` を適用し、その結果を格納して、新しい値を返します。関数値としても動くため、`map`/`reduce` を渡れます。

Clojure と同じく compare-and-set の再試行ループです。`f` はロックの外で実行され、その間にアトムが変わっていれば（別スレッドで変わった場合と `f` 自身が変えた場合。インタプリタと JVM では Ring のハンドラがリクエストごとに一つのスレッドで動きます）、新しい値に対して `f` をもう一度実行します。更新は失われず、`f` は複数回実行されることがあります。

```clojure
(def a (atom 1))
(println (swap! a + 10 20)) ; 31
(println @a)                ; 31
```

アトムでないものへの誤用はシグナルを上げます。`add-watch`/`remove-watch` はなく、watch は名前で拒否されます。
