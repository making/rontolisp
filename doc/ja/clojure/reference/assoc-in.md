# assoc-in

`(assoc-in m keys v)`

キーベクターを下るネストした関連付けを返し、欠けた階層は空から作ります。キーが空なら
オラクル同様 `nil` の下に関連付けます。ベクターの階層は [assoc](assoc.md) と同じく添字で
進み、要素数と等しい添字は新しい階層を末尾に追加します（`(assoc-in [[0 0]] [1 0] :x)` は
`[[0 0] {0 :x}]`）。値としては実行時にキー列をたどります。

```clojure
(println (assoc-in {} [:a :b] 1)) ; {:a {:b 1}}
(println (assoc-in [[0 0] [0 0]] [1 0] :x)) ; [[0 0] [:x 0]]
```
