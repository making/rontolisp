# rand

`(rand)` / `(rand bound)`

プログラム所有の生成器による1回の抽選です（1抽選につきホスト呼び出しはしません）。
引数なしでは `[0,1)` の倍精度浮動小数点数、引数ありでは1回のスケール済み抽選です
（ドメインチェックはしません -- 負の bound には負で答えます。oracle の掛け算と同様です）。
固定されるのは述語だけで値は固定されません。値としては0引数・1引数形に対する
rest ラムダです。

```clojure
(println (let [r (rand 5)] (and (<= 0.0 r) (< r 5)))) ; true
```
