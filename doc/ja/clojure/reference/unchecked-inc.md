# unchecked-inc

`(unchecked-inc x)`

整数の`x` に1を足した値を64ビットに折り返して返すので、`(unchecked-inc 9223372036854775807)` は `-9223372036854775808` です。doubleと比は通常の結果です。`nil` と非数はシグナルします。値としては1引数の関数です。

64ビットを超える整数もここでは通常の整数なので、オラクルでは折り返されない bigint（`100000000000000000000N`）も折り返します。

```clojure
(println (unchecked-inc 9223372036854775807)) ; -9223372036854775808
```
