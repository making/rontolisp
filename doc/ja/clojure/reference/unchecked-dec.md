# unchecked-dec

`(unchecked-dec x)`

整数の`x` から1を引いた値を64ビットに折り返して返すので、`(unchecked-dec -9223372036854775808)` は `9223372036854775807` です。doubleと比は通常の結果です。`nil` と非数はシグナルします。値としては1引数の関数です。

64ビットを超える整数もここでは通常の整数なので、オラクルでは折り返されない bigint（`100000000000000000000N`）も折り返します。

```clojure
(println (unchecked-dec -9223372036854775808)) ; 9223372036854775807
```
