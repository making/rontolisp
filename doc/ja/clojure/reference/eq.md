# =

`(= x...)`

連鎖の隣接要素を比較します。隣接するすべてのペアが等しければ `true`、引数 1 つなら常に `true` です。マップはエントリ単位、セットは要素単位、シーケンシャル（ベクター、リスト、遅延 seq）は種類をまたいで要素単位で、いずれも深く構造的に比較します。文字列はシーケンシャルではありません。`nil` は空のシーケンシャルと等しくなります（ここでは `nil` が空リストだからで、本家は `(= [] nil)` に `false` を返します）。比較は truthiness ではなく `equal` 型です。2 つのオブジェクトが別物なので `(= false nil)` は `false` です。左辺の Java オブジェクトには本家と同様にそれ自身の `equals` で尋ねるため、`(= o 1)` は数値を `equals` に渡し、`(= 1 o)` は `false` です。`false`、キーワード、シンボル、コレクションを `equals` に渡すことはありません（本家は渡します）。Java の `List`、`Map`、`Set` は、`=` な要素を持つ Clojure のシーケンシャル、マップ、セットと、どちらが先でも本家と同じく `=` になります。同じアリティの関数値として動きます。

```clojure
(println (= 1 1 1)) ; true
(println (= 1 1 2)) ; false
(println (= {:a [1 2]} {:a [1 2]})) ; true
(println (= [1 2] '(1 2))) ; true
(println (= false nil)) ; false
```
