# ->

`(-> expr step...)`

`expr` を各ステップへ通します。リストのステップには値を第 2 要素として挿入し、裸の名前やキーワードは値を引数に呼ばれる/読まれ、最後のステップの値が結果になります。スレッド化した呼び出しへ datums として書き換えて低レベル化されます。コレクションリテラルに対するステップはシグナルを上げます（ここではコレクションは関数ではありません）。

```clojure
(println (-> 5 inc inc))               ; 7
(println (-> {:a 1} :a))               ; 1
(println (-> [1 2] (conj 3) (conj 4))) ; [1 2 3 4]
```
