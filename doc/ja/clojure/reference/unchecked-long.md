# unchecked-long

`(unchecked-long x)`

整数の下位64ビット（比は切り捨てた値）を符号付き整数として返すので、`(unchecked-long 9223372036854775808)` は `-9223372036854775808` です。doubleは先に64ビットの範囲へ飽和させます（NaN は `0`）。文字・`nil`・非数はシグナルします。値としては1引数の関数です。

```clojure
(println (unchecked-long 9223372036854775808) (unchecked-long 1e20)) ; -9223372036854775808 9223372036854775807
```
