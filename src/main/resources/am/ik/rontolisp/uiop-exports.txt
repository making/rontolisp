# uiop 3.3.7 -- the external symbols of every sub-package `uiop` re-exports.
#
# Extracted from the pinned sources the built-in Quicklisp client fetches
# (~/.rontolisp/quicklisp/software/uiop-3.3.7/), read with a PORTABLE feature set:
# the three implementation-conditional exports (use-ecl-byte-compiler-p on
# clasp/ecl, probe-posix on mcl, sb-grovel-unknown-constant-condition on sbcl) are
# deliberately absent.
#
# Format: <sub-package> TAB <symbol> TAB <kind>, one row per EXPORT (a symbol two
# sub-packages both export gets a row in each -- upstream's uiop/backward-driver
# re-exports five uiop/configuration names, and *output-translation-function* is
# exported by both uiop/pathname and uiop/lisp-build). Sub-packages appear in
# upstream LOAD order and symbols alphabetically within one, so the FIRST row for a
# symbol names its HOME package and every later row is an import redirect --
# PackageRegistry builds the tables that way. Lines starting with # and blank lines
# are ignored.
#
# 435 rows / 429 distinct symbols / 15 sub-packages.
#
# kind is upstream's DEFINITION form, so a stub can be the right shape:
#   function  defun / defgeneric / defmethod / a condition slot reader
#   macro     defmacro / define-modify-macro
#   variable  defvar / defparameter (upstream really spells +cr+ and friends this way)
#   constant  defconstant
#   condition define-condition        class     defclass        type      deftype
# A name upstream defines twice carries both, joined with + (not-implemented-error
# is a condition AND the function that signals it).
#
# See .kb/uiop.md. Regenerate rather than hand-edit: the extractor is recorded there.
